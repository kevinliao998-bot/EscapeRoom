# 《黃燈之後》MW 網頁與機關

採 main 完整版 brief.md：迴圈走廊、安全梯間、站務室、檔案室、月台走廊，以及兩個明確選擇的結局。原劇本與協作規範保留不改。

## 開啟方式

直接以瀏覽器開啟根目錄 `index.html` 或 `Game/index.html`。全部資源使用相對路徑，沒有 fetch、外部字型、CDN 或後端需求。

開發預覽可在根目錄執行 `npm start`，開啟顯示的 Local URL；測試執行 `npm test`。沒有 npm 時，可用 Node 執行 `node Game/serve.cjs` 與 `node --test Game/tests/*.test.cjs`，兩者完全等效且不需安裝依賴。

靜態部署時需保留整個 Game/ 和根目錄 index.html。GitHub 本身的檔案預覽不是遊戲；要下載後開啟或由 TI 部署到靜態網站。此分支沒有啟用或變更 GitHub Pages。

## 操作

- 點擊場景標記或右側操作；鍵盤可 Tab 移動、Enter／空白操作，Escape 關閉視窗。
- 點背包物品，再點場景設備；設備視窗也提供等效的「使用物品」按鈕。
- 「紀錄對照」可比較已走過的迴圈；「調查筆記」可重看證據。
- 提示逐級開啟，不自動解題、不扣分；計時記錄有效遊玩時間，沒有倒數。
- 字幕與非音訊線索始終提供，聲音預設關閉。設定可放大文字、減少動態與調整分項音量。
- 每次進度變更立即保存，計時定期保存；切到背景或離開時也嘗試保存。資料僅在目前瀏覽器／網址的 localStorage，不會同步到其他裝置；無痕模式、儲存限制或清除網站資料會影響保存。
