# MW 視覺規格：現代極簡與 2D 空間感

## 設計系統

原生 CSS 變數集中於 `Game/styles.css` 的 `:root`，依變數、基礎元素、導覽、首頁、探索、彈窗／機關、結局、響應式分段。沒有加入 Tailwind 執行時或外部 CDN。

| 用途 | 變數／規則 |
| --- | --- |
| 背景 | `--bg: #0c0e11` 碳黑，微量灰色徑向漸層 |
| 卡片 | `--surface: #15171b`、`--surface-raised: #1c1e23` |
| 文字 | `--ink: #f1eee8` 象牙白；次要文字 `--muted: #b1b0b3` |
| 單一點綴色 | `--accent: #cbb18b` 香檳金；選取、主要按鈕與供電提示共用 |
| 圓角 | 卡片 16px、按鈕 12px；外層首頁／結局使用 24px |
| 層次 | 細邊框、內側高光、低濃度柔和陰影；局部透明玻璃表面 |
| 字體 | Inter（裝置已安裝時）、Apple 系統字體、微軟正黑體等無襯線字體；無字型下載 |
| 互動 | 240ms ease-in-out；懸停上浮 2px，按下回落；有清楚鍵盤焦點 |
| 舒適度 | 保留放大文字、減少動態；同時遵循系統 prefers-reduced-motion |

## 場景層次

所有畫面仍為 SVG 2D 圖像與 HTML 熱點。以消失點透視、天花板結構、牆面接縫、地磚縮短、金屬／煙灰玻璃漸層、物件投影、燈光錐與前景遮擋呈現深度。沒有 WebGL、3D 模型或透視鏡頭控制。

每次產生場景時，SVG 的漸層、陰影、裁切與材質 ID 加入唯一前綴，避免首頁、遊戲與紀錄對照同時存在時引用到另一張隱藏場景。場景光線不加入頻閃或循環晃動；環境層只以 11–28 秒的緩慢變化呈現微光、水面反射與六粒低濃度灰塵。

637px 及更窄畫面將場景、背包與目標卡片依序排列；800px 以下為單欄，480px 以下將工具列與行動按鈕展開。必要內容不依賴 Hover；觸控／鍵盤仍有文字按鈕可操作。

## 參考與證據邊界

視覺方向參考 [Playdead《INSIDE》官方商店頁](https://store.steampowered.com/app/304430/INSIDE/) 對氛圍、美術與敘事解謎的介紹，僅採用「克制光線與清楚焦點」的設計方向。未下載或複製其圖片、角色、模型、音效或程式碼。

本次依使用者提供的 Modern & Quiet Luxury Minimalist 規範重作樣式。視覺質感與玩家留存並不等同；是否讓新玩家更願意繼續遊玩，仍需盲玩觀察與比較，不宣稱已有留存數據。


## 情境調查與道具互動

- `interaction-model.js` 維護物件在 2D 場景中的實際範圍、材質與解鎖前提。按鈕只保留輔助名稱，不常駐顯示框線或文字。
- 滑鼠距物件約 40px 時微弱浮現圖示，懸停／鍵盤聚焦加強光暈；紙張與線索使用放大鏡游標、拾取使用手掌。未解鎖的出口與已拾取物品不建立熱點。
- `immersion.js/css` 負責場景內特寫。紙張有膠帶、紙紋與折角；站牌有金屬邊緣、螺絲與當前方向；鐘面及水漬依目前繞行呈現，不提前透露鞋印。背景以物件位置為原點微微拉近，Escape 或關閉鈕回到場景。
- 背包可單擊選取並點目標、Pointer Events 真正拖放，或使用文字操作按鈕。選取後有跟隨游標的原創 SVG 道具；取得時有一次性柔光，合適目標微亮。錯誤拖放由核心再驗證，不消耗物品。Escape 可收回。
- 手帳以泛黃雙頁呈現已取得的紀錄，可固定最多三筆到對照頁、重讀全文；固定紀錄另存本機，不改舊遊戲存檔格式。新調查會清空對照頁。
- 音效依紙張、金屬、水面分開合成。預設關閉，使用者開啟後才播放；靜音立即切斷總輸出，背景頁面停止音效。全程不靠聲音才能解題。
- 粗指標／無 Hover 裝置保留淡淡圖示，且有等效文字操作；減少動態會停用拉近、灰塵、水紋及取得閃光。這些支援不代表已完成實體觸控或螢幕閱讀器認證。
