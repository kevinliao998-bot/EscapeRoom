## 實際瀏覽器操作

正式建置使用獨立的 `localhost:4175` 測試存檔，未注入隱藏狀態。以知道答案的滑鼠操作，加上實際 Escape／Tab／Shift+Tab／Enter 及音量鍵盤調整完成。不是完整純鍵盤通關或新玩家盲測。

1. 閱讀工單；Escape 返回同一物件，下一次 Tab 到五回路插槽，Enter 可開啟。
2. 閱讀固定架及接頭圖。送出錯誤排列後草稿保留；重新接正五條線，三個初始分路恢復，共 3／4 格。
3. 泵浦接通會超載；門鎖在高水位時被拒絕。關閉通訊及排風後，檢修窗可讀到 C 回流，線索入筆記。
4. 啟動泵浦，先關 D、保留 C 開啟，實際收到回流回饋且水位不降。再關 C，水位變安全。
5. 重新整理並繼續，回到泵房、水位安全、負載 4／4。回配電室停泵，止回閥閉合、水位保留；接通門鎖後 3／4。
6. 到前廳確認感測器安全、門鎖接通、止回閉合，開門後顯示原文工單與本切片完成說明。完成後重載仍可重看。
7. 設定面板的 Shift+Tab／Tab 循環、加大字及音量滑桿重繪後焦點保留；勾選靜音、減少動態可繼續操作。
8. 實際點選匯出，收到下載請求回饋。序列化內容及儲存失敗後取目前進度由單元測試驗證；**本輪未獨立打開實際下載到磁碟的 JSON**。

16 筆原始觀察、最終 JS／CSS 檔名與空的警告／錯誤清單見 [browser-check.json](browser-check.json)。完整路徑驗證後，另外清理已完成接線的選取名稱及提高紙張副標對比；最終正式包已重載複核完成存檔與中文工單。畫面見 [泵房](b1-pump.png)、[完成工單](b1-workorder.png)。

開發中曾發現 Phaser 的 SVG data loader 需要 Base64，且直接 UTF-8 位元組會把中文解成亂碼。已改為 ASCII XML 數字實體加 Base64；正式頁實際檢查中文可讀、最終 console 無錯誤。這是本輪修復過程，沒有隱藏成一開始就成功。
