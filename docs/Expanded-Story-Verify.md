## 謎題一：排列唯一性檢查

測試應枚舉五條回路的所有排列，確認所有線索同時成立時只有一種解：

- 照明位於通訊左側；排風位於通訊右側。
- 門鎖緊接在泵浦右側。
- 通訊與泵浦位置差為 2。
- 排風不在第 5 槽。
- 五條回路各出現一次。

唯一解應為「照明、通訊、排風、泵浦、門鎖」。若內容資料或遊戲回饋容許第二種排列，先修正線索或答案再實作。

## 謎題二：水路狀態檢查

- A 與 B 必須同時開啟才建立積水槽至排水井的通路。
- C 開啟時形成回流，泵浦雖運轉但水位不下降。
- D 開啟時不得把水送入封存室；系統應以可理解的回饋指出路徑錯誤。
- 正確狀態 A/B 開、C/D 關時水位下降。
- 停泵後止回閥閉合，水位不回升至危險線。

## 謎題三：負載與安全檢查

- 供電上限為 4 格；照明 1、通訊 1、排風 1、泵浦 3、門鎖 2。
- 排水階段：照明 + 泵浦 = 4 格；通訊及排風須關閉。
- 門鎖階段：泵浦停止後，照明 + 門鎖 = 3 格。
- 水位未達安全線時門鎖不可啟動；停泵後止回閥閉合，水位狀態維持安全。
- 任何超載都不得清除回路解法、閥門狀態或已取得文件。

## 內容 TDD 建議

未來把內容轉為機器可檢查資料後，測試至少涵蓋：

1. 每層房間、線索、文件、提示及答案 ID 唯一且可引用。
2. 每題恰有三級提示，提示方向與正解相容。
3. 所有可行回路排列只有一組解。
4. 閥門答案及水流方向與圖示、文字一致。
5. 電力總量、負載與操作先後符合安全規則。
6. 每項故事揭露都有至少一項先前或同期可重查的證據。
7. 結局不超出證據能支持的結論；廣播錄音不能單獨證明身分。
8. 所有玩家必須理解的音訊資訊都有文字或視覺替代。
