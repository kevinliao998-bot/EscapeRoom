# 02｜一頁美術風格指南：冷色站務檔案

**狀態：2026-11-03 使用者「按預設確認」核准。** 選 A：俯視角像素、略見物件正面。以重複走廊、穩定螢光燈、壓克力站牌、褪色黃線、琥珀供電燈建立原創辨識；不用農場資產、暖飽和田園配色、木框 HUD 或參考圖布局。

**描邊與光影：** 外輪廓 1px，同色系暗階；禁純黑。光源固定左上，右下投影偏移 1–2px，用 2–3 級色階做柔邊；不模糊、不用半透明濾鏡引入大量新色。壓克力用雙邊高光與稀疏點陣反射。琥珀三色只給關鍵線索、供電燈與出口；普通按鈕／焦點用冷白或淺冷綠。地面黃線未供電時用褪米色，採信路徑由穩定琥珀燈確認，不能只靠顏色。

**地塊與分層：** 基礎 16×16；地圖 30×16 格＝480×256，置於 480×270 畫布上下各 7px。地面 → 地面線條／水漬 → 物件下部 → 角色與高物件依腳底 y 排序 → 前景上部 → 互動／文字層。前景不能完全遮住角色及唯一線索；以固定 cutaway 削開牆頂，不靠透明漸變。三場景各一張固定視野地圖，不做快速追鏡。

**角色：** 林澄約 16×24px；灰藍維修外套、冷綠工作褲、短髮與側腰工具袋，不用草帽或田園服裝。四方向各 4 帧，畫格 16×24，暫定精靈表 64×96；6fps、48px/s，靜止取重心幀。腳底碰撞 8×6px，位置與相機顯示對齊整數像素，沒有以整格瞬移代替走路。

**HUD／面板：** 左側壓克力板約 36×164px，四個固定直排格；卡／撬片／路線片／電池各一格，圖示約 16px，命中區至少 32×32px。左側 48px 列為牆面留白區，不藏線索。右上筆記本，右下設定；沒有獨立 HUD 時鐘、金幣、體力或底部工具列。時鐘在場景中，可近看。三種近景面板共用 1px 框、4px 內距倍數、灰藍底，重要文字不直接浮在雜色背景。記錄櫃提供「選起點→選終點」等效操作，不強制拖曳。

**字與可讀性：** 建議 Fusion Pixel Font 12px 的繁體字形版本；普通像素字 12px、大字 24px，1 倍時可選大字／文件獨立捲動閱讀，不縮字藏內容。匯入時固定版本、檢查繁體文本缺字、附完整 OFL／上游授權並列 Credits；已固定 2026.10.25 版，完整上游授權隨專案提供。[上游與授權](https://github.com/TakWolf/fusion-pixel-font/blob/master/LICENSE-OFL)。

**對比度與安全：** 灰白字／墨藍 13.49:1、灰白／深灰藍 9.41:1、淺冷綠字／深灰藍 5.67:1、墨藍字／舊紙 10.75:1、灰白／冷綠 5.64:1。僅准用已驗證字色組；灰白／灰藍 4.13:1 與暖灰／深灰藍 4.37:1 不得作正文。18 色限制先驗收貼圖；畫面以最近鄰取樣，燈光／淡出用色階替換，避免任意混色。HTML 可及閱讀層單獨檢查對比，不假稱瀏覽器文字抗鋸齒也只含 18 色。

**動態與工具：** 零頻閃、零呼吸亮度燈、零抖鏡；結局淡出單向約 0.8–1s，減少動態時以靜態卡替代。字幕及字級可調，主／環境／音效／語音音量獨立且可靜音。確認後才用 Aseprite 類工具建立原創圖層、索引色、去除孤立像素、檢查幀對齊，輸出最近鄰 PNG；每張原稿及導出記錄實際作者、來源、授權與 SHA256。工具授權不代表參考截圖素材可用。[Aseprite 官方 FAQ](https://www.aseprite.org/faq)。
