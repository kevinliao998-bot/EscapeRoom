## 純鍵盤：可到雙結局，焦點返回未通過

使用獨立 HTTP 測試進度，從新遊戲起只透過 Tab、Shift+Tab、Enter、Escape、E 及方向鍵操作遊戲；沒有點擊遊戲物件，也沒有寫入通關狀態。瀏覽器開頁／視窗前景屬測試設定。

- 從開場取得卡與工具、開盒供電、波形、壓痕與兩條證據線、取得路線片／電池、兩設備裝配、供電節點，到達甲，再讀檔／重選到乙。
- 設定的核取方塊、音量滑桿、兩種匯出可用鍵盤操作。面板中 Shift+Tab 可回最後一個按鈕、Tab 循環回第一個按鈕，見 `modal-tab-wrap.json`。
- 工具送出的 Ctrl+R 與 F5 沒有觸發 Chrome 重載；由使用者實際按一次 F5 協助，觀察到重載後的「繼續 · 重看結局」選單，再以鍵盤繼續。不能把這一步寫成完全由 Codex 獨立完成。
- `keyboard-trace.json` 保存 417 筆工具鍵盤輸入紀錄及真人 F5 註記；包括初期背景分頁等待與未觸發重載的請求，不以筆數當有效操作或貢獻次數。
- 兩種實際下載已保存為 `keyboard-progress.json`、`keyboard-recovery.json`；進度可 restore、lastEnding=B、seenEndings=[A,B]、檢查點存在，原檔包 SAVE 與進度相同。
- 初期背景分頁暫停角色移動，切到前景後可繼續；未將此歸為遊戲尋路錯誤。E 調查是在確認角色附近有物件後才列為成功。

**確認問題：** 關閉面板後焦點落到 BODY，下一個 Tab 從背包門禁卡重新開始，不回到觸發調查的物件。牆腳卡槽、推車及紀錄櫃均觀察到。證據：`focus-return.json`、`focus-return.jpg`；重現詳見 `focus-issue.md`。因此「能用鍵盤通關」與「鍵盤／焦點完整驗收通過」分開判定，後者目前未通過，交 Li 修復。

## 首次盲測回報

使用者回報：「用了20分鐘，自行達到結局，用了4張提示卡。」另確認已完成首次通關。此為在 Redmi K80 上進行的一位真實新玩家（P01）的觀察者回報，並非 Codex 自己扮演受試者。約 20 分鐘位於設計目標 15–20 分鐘的上緣，但只有一個樣本，不能推論全體玩家的遊玩時間與難度。4 張提示卡照原話記錄，不自行換算成 4 題或某一級提示。

精確起迄未提供，不從聊天或等待時間倒推出通關時間。手機首次通關可作觸控基本流程的回報；旋轉、重整、另一結局、設定及下載在首次盲玩後另行確認如下。

後續補查已由使用者逐組確認「四項都正常」：直／橫向回復、重整後續玩並選另一結局、大字與面板捲動／關閉、兩種檔案確實下載到手機。首次盲測補充為結局乙，提示卡用於電池與路線；沒有擅自補入每題次數或提示級數。

## 手機音訊回報與複核

使用者先回報遊戲三聲聽不到，並一度將「其他聲音是否正常」回答錯，後來明確更正為其他聲音正常。確認耳機接手機後，首次盲玩結束才要求檢查遊戲靜音與音量並實際點試聽；使用者回報試聽有聲。再單獨詢問三聲重播是否清楚、預設耳機音量有無不適，回覆「都 OK」。因此本次已取得實聽正常的觀察者回報，但沒有找出首次無聲的確定原因，不將其偽報為已確認並修復的程式 bug。

## 螢幕閱讀器執行方式

使用 Windows 內建 Narrator，不安裝額外程式。啟動時出現「Narrator updates」視窗，關閉非必要說明後保留 Narrator 執行。朗讀由使用者實聽核對，不由 Codex 聲稱自己聽見。重讀目前項目使用預設 Narrator 鍵（Caps Lock 或 Insert）＋Tab；朗讀方法參考 [Microsoft 官方說明](https://support.microsoft.com/en-us/accessibility/windows/narrator/chapter-4-reading-text)。

使用者實際回報依序為「完全聽得見」、「調查面板，減少動態效果」，以及對狀態問題回答「有。scan chat.」。最後一句後半意義不明，未自行猜譯。工具將 DOM 焦點移到總音量（0.45）後，使用者只聽到「調查面板」，因此該次滑桿核對未通過。改由使用者在前景遊戲直接按 Tab、右方向鍵，對名稱與數值的問題回答「有」，但沒有提供逐字數字。後續控制連線中斷，亦無法再讀取該次操作後的值。這些結果不足以判定一個確定的滑桿程式錯誤，也不足以給整體螢幕閱讀器驗收通過；不能將 DOM 的 0.45 寫成使用者實際聽到的值。

最後改由使用者關閉設定、回到最後選擇前並開啟筆記，以 Insert＋R 朗讀、Ctrl 停止。對是否能唸出線索句子的問題，回覆「能聽到全部」。此為筆記文字實聽的肯定回報，未取得逐句轉錄，不能擴張為每一場景與每一種回饋均已檢查。使用者最後回報 Narrator「已關閉」。
