# 故事內容資料

此資料夾維護故事主線、區域謎題、線索、提示、答案與故事邏輯。遊戲程式不得自行複製一套互相矛盾的答案；若 MW 實作需轉換資料，轉換後須由 SC/TI 對照本目錄核驗。

## 檔案

- `story.json`：角色、故事前提、揭露順序、遊玩範圍與結局。
- `puzzles.json`：謎題識別碼、所在區域、前提、線索和解鎖結果。
- `clues.json`：可重查線索、來源、文字內容及無障礙替代。
- `hints.json`：每組謎題三級提示。
- `answers.json`：接受答案、支援證據、成功結果與不得推論事項。
- `logic.json`：房間順序、狀態條件、故事不變規則與結局條件。
- `tests/story-content.test.cjs`：不依賴外部套件的結構與一致性檢查。

## TDD 工作方式

先新增或調整測試，確認新規則能被測試描述；再修改 JSON 內容直到測試通過。測試通過後仍需由 SC 閱讀故事文案，並由 TI 檢查整合後的遊戲狀態。自動測試不能取代故事審稿或真人盲玩。
