# 圖像與音效素材

素材方向依 MW 的 `Game/Design.md`：現代極簡、碳黑／深灰背景、象牙白文字、香檳金點綴，使用具空間深度的原創 2D 圖像。不得使用頻閃、突發大音量或未授權素材。

- `manifest.json`：每項素材的路徑、替代文字、來源、授權、狀態和用途。
- `graphics/`：五張原創 SVG 場景草稿，對應迴圈走廊、安全梯間、站務室、檔案室及月台。
- `audio/effects.js`：由玩家互動才呼叫的紙張、金屬、水滴及電力提示音；不自動播放，並設低音量上限。
- `tests/asset-manifest.test.cjs`：檢查素材檔案、SVG 結構、替代文字、音效設定和授權欄位。

目前素材狀態為 `in-review`。檔案已建立為第一版草稿，仍需 SC 審閱畫面與線索位置，並在實際耳機／喇叭聆聽音量、音色與舒適度。尚未標記 `approved`。

## TDD 驗收

先以測試定義素材路徑、SVG 標題與描述、唯一圖形 ID、繁體中文替代文字、來源與授權欄位，以及音效靜音預設和低音量上限。建立測試後再新增 manifest 和素材。自動測試只檢查結構及必要欄位；SC 仍需目視檢查構圖、對比、線索辨識，並實際聆聽音效。
