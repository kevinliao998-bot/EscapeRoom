# 圖像與音效素材

素材方向依 `Game/Design.md`：現代極簡、碳黑／深灰背景、象牙白文字、香檳金點綴，使用具空間深度的原創 2D 圖像。不得使用頻閃、突發大音量或未授權素材。

- `manifest.json`：每項素材的路徑、替代文字、來源、授權、狀態和使用目的。
- `graphics/`：規劃中的場景與線索圖像。
- `audio/`：規劃中的環境底音及互動音效。
- `tests/asset-manifest.test.cjs`：檢查素材清單、無障礙替代文字、授權欄位及安全要求。

目前 manifest 中的素材皆為 `planned`。這裡記錄的是規格和待製作清單，尚未代表圖像或音效成品已交付。

## TDD 驗收

先用測試規定素材需有唯一路徑、繁體中文圖像替代文字、來源與授權狀態，以及音效的文字／視覺替代。製作素材後更新 manifest，再跑測試。自動測試只檢查清單與必要欄位；SC 仍需目視檢查構圖、對比和線索辨識，並實際聆聽音量、刺耳度和循環接縫。
